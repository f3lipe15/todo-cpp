# ✅ ToDo App w C++ (wersja konsolowa)

Prosty terminalowy program ToDo napisany w języku C++.  
Pozwala dodawać, przeglądać, oznaczać jako wykonane oraz usuwać zadania.  
Działa w terminalu, zapisuje dane do pliku `tasks.txt`.

---

## 🔧 Funkcje

- 📝 Dodawanie nowych zadań
- 📄 Wyświetlanie listy zadań
- ✅ Oznaczanie jako wykonane
- 🗑️ Usuwanie zadań
- 💾 Zapis do pliku tekstowego

---

## 🚀 Jak uruchomić

### 🔹 Kompilacja (lokalna)

```bash
g++ main.cpp -o todo
./todo
